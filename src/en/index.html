    Why nothing is transmitted here

    Everything stays in your browser

    The calculation runs entirely on your device. There is no server that receives your input; it is not stored anywhere.

    No trackers

    No cookies, no analytics, no fonts or scripts from other servers. The page only loads files from this address.

    Verifiable

    The source code is open. In your browser's developer tools (“Network” tab) you can see that calculating sends no request.

    OwnYourData is a non-profit association working for data sovereignty: people should decide for themselves who gets which data about them. This calculator shows that a useful tool works without collecting any data at all.
